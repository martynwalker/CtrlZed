# ColourPicker
Native Win32 tray colour picker for The Design Factory Utilities range.

Click the tray icon to enter pick mode. Hover to see the sampled colour as RGB and HEX. Left-click copies RGB(r, g, b) to the Windows clipboard; right-click cancels. No installer is required.

Build verification runs the executable's /test routine before producing the Windows x64 artifact. Interactive screen sampling remains a manual Windows-desktop test.
